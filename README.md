# Goblin Forge Team

The shared forge for GRE3NZ89 and his AI goblin crew: commands, messages, decisions, and finished work in one place. Main project: GFG Goblin Forge Gaming, our Discord community centred on Borderlands 4.

**All Free All Fun.** GFG motto: **Forged By Goblinz 4 The Goblinz.**

## Start here

1. Meet [the team](TEAM.md).
2. Copy [the command template](commands/template.md) to `commands/YYYY-MM-DD-short-name.md` and fill it in.
3. Tell an AI to read the command. It claims the work, saves the result, and links it from the command.

Read [HOW-TO-USE.md](HOW-TO-USE.md) for the complete workflow and access setup.

## Forge rules

- Private repository only; no public sharing.
- Never commit passwords, API keys, tokens, private member records, or personal files.
- Use lowercase dashed names and YYYY-MM-DD dates. The explicitly requested root documentation names and folder READMEs are exceptions.
- Every command and message identifies its date, sender, and recipient.
- Preserve other people's work. Add dated files or attributed dated sections; never replace their content.
- Keep it clear, welcoming, professional, and fun. No hate speech.

This repo is a shared noticeboard, not a running multi-agent service. Creating it does not connect AI apps, wake them, grant access, or make them monitor commands automatically. Each AI needs an authorized active session or a manual paste from Green. No paid services or automation are required.
